## 2. Описание ключевых файлов

### Обязательные файлы по `TASK.md` (§ 4)
1. **`01_analysis.ipynb`** — чистовой рабочий документ. Содержит загрузку сырых данных из `data/`, полный аудит качества данных, выявление пропусков и выбросов, журналирование предобработки, расчёт среднемесячной активности, визуальный и корреляционный анализ, проверку гипотез (формат «гипотеза $\to$ проверка $\to$ вывод») и формирование целевых групп. Ноутбук исполняется сверху вниз без ошибок.
2. **`02_report.ipynb`** — управленческий отчёт для руководителя департамента розничных продуктов. Содержит все 8 обязательных разделов, 5 лаконичных графиков (лимит: $\le 8$) и выводы без технического шума.
3. **`report.pdf`** — отчёт, экспортированный в PDF объёмом **ровно 6 страниц** (строго соблюдено ограничение: не более 6 страниц А4).
4. **`cleaning_log.csv`** — журнал изменений на 22 строки с обязательными полями: `field`, `issue`, `scope`, `n_rows`, `value_before`, `action`, `value_after`, `rationale`.
5. **`campaign_list.csv`** — реестр отобранных клиентов для маркетинговой кампании. Содержит колонки `client_id` и `group`. Ровно 1779 уникальных клиентов (лимит $\le 2000$).

### Наборы данных
* **`data/clients.csv`** и **`data/transactions.csv`** — исходные персональные файлы данных банка «Меридиан».
* **`clean_clients.csv`** и **`clean_transactions.csv`** — очищенные таблицы, сформированные первым ноутбуком и используемые вторым ноутбуком.

## 3. Целевые группы для кампании

Сформировано 4 взаимоисключающих сегмента на **1779 клиентов** (бюджет $\le 2000$ чел., каждый сегмент $\ge 150$ чел.):

| Группа | Размер ($n$) | Правило отбора | Причина спада | Рекомендуемое действие |
|---|:---:|---|---|---|
| **G1_mass_no_app** (Массовый офлайн) | 428 | `segment == 'Массовый'` $\land$ `has_mobile_app == False` $\land$ $\Delta Activity \ge 1.0$ | Потеря цифрового контакта, спад вдвое выше нормы (-25.2%) | Бонус 500 руб. за установку мобильного приложения |
| **G2_nnovgorod** (Нижний Новгород) | 468 | `city == 'Нижний Новгород'` $\land$ $\Delta Activity \ge 1.0$ | Локальная конкуренция / региональный фактор (-27.6%) | Повышенный кешбэк 7% в местных розничных сетях |
| **G3_transport** (Отказ от транспорта) | 488 | $\Delta TransActivity \ge 0.75$ | Переход на карты других банков / транспортные карты (-33.8%) | Кешбэк 20% на транспорт и такси на 2 месяца |
| **G4_plastic** (Пластиковые консерваторы) | 395 | $\Delta CardActivity \ge 1.0$ $\land$ $TokenActivity_{2025} \le 0.5$ | Спад оплат пластиком без перехода на Pay-сервисы | Бесплатный платёжный стикер или акция по Mir Pay |

Все клиенты имеют `marketing_opt_in == True`.
